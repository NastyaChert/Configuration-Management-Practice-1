## Задание
Разработать эмулятор для языка оболочки ОС. Необходимо сделать работу
эмулятора как можно более похожей на работу в командной строке UNIXподобной ОС.
## Реализованные команды
* `ls` — вывод содержимого виртуальной директории.
* `cd` — смена текущей виртуальной директории.
* `exit` — завершение работы эмулятора.
* `clear` — очистка экрана терминала.
* `echo` — вывод текста/аргументов в консоль.
* `chmod` — симуляция изменения прав доступа к файлам в памяти.

Для запуска эмулятора выполните команду:

python main.py --vfs "путь/к/папке" --script "script.txt"
